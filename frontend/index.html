Stand-in for Usha’s system

LiSN — Collector Console

This page pretends to be LiSN: the system that asks our collector for Sentinel data. It exists so a non-technical viewer can see how requests are made — without watching someone type curl.

API connection

The deployed Cloud Run API requires authentication. Do not put identity tokens in this page, and do not make the API publicly invokable. Reach it with a local proxy so the browser talks to localhost and gcloud attaches the token: 

gcloud run services proxy collector-api --region=asia-south1 --port=8080

Then leave the base URL as http://localhost:8080.
